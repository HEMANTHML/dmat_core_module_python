# dMAT Core Module Generator

A Python tool designed to generate infinite, randomized practice problems for the **dMAT (Digitaler Mastertest) Core Module**.

This program was created using the task-specific rules and examples provided in the official [APS Preparatory Materials](https://www.d-mat.de/wp-content/uploads/2026/07/260716_dMAT_General-Academic-Module_Preparatoy-Materials_EN.pdf). It strictly follows the Core Module formatting to ensure the logic and constraints match the actual exam. Because the script generates a completely random set of problems every single time it runs, you will never run out of fresh material to practice your mental arithmetic and working-memory heuristics.

## Usage

To use this generator, clone the repository to your local machine and run the script via your terminal. The program takes the desired output file path as an argument and generates a PDF with your practice set.

**Syntax:**
```bash
python3 <filename.py> <location_you_want_the_pdf_to_be>
```
Example Command:

```bash
python3 generator.py /Users/hemanthhml/Desktop/Dmat/math_eqns.pdf
(Note: Replace generator.py with the exact name of the script in the repository, and update the file path to wherever you want the PDF saved on your computer).
```
